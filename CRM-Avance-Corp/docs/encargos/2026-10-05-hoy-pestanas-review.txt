FINDINGS:

[P3] Polling can cancel an in-flight "Cargar más" and drop focus restoration
File: src/screens/hoy/use-leads-recibidos-hoy.ts
Lines: 21-27 (with use-cartera-paginada.ts:136,139 and leads-recibidos-hoy.tsx:28-36)
Problem: The 60 s interval calls cartera.recargar(), which is consulta.refetch(). It is not gated on cartera.cargandoMas.
Evidence: The manual refresh button is disabled while cargando or cargandoMas (leads-recibidos-hoy.tsx:49), but the interval is not. TanStack's refetch() defaults to cancelRefetch:true, which cancels a running fetchNextPage. The focus effect then sees cargandoMas=false and no new rows and no error, so it clears enfocarDesde without moving focus.
Impact: This is rare, only when a poll lands during a page load. The user has to click "Cargar más" again, and keyboard focus is not moved to the first new row. The count itself stays correct.
Recommendation: In the interval, skip the tick when a fetch is already running (expose cargandoMas or isFetching through a ref, like recargarRef). Alternatively, call refetch({ cancelRefetch: false }).

[P3] Each poll refetches every loaded page
File: src/screens/hoy/use-leads-recibidos-hoy.ts:24 -> use-cartera-paginada.ts:139
Problem: Infinite-query refetch() re-requests every page already loaded, in sequence.
Impact: An analyst who loaded N pages sends N RPC calls per minute while HOY is visible. The badge only needs page 0's resumen. This is negligible for typical daily volumes.
Recommendation: Accept it and document it, or limit the poll to the first page (for example with refetchPage or maxPages semantics) if daily volumes grow.

[P3] The empty citas card now stretches to full height
File: src/screens/hoy/vendedor.tsx (integration diff, CitasAnalista className)
Problem: The conditional `citas.length > 0 && 'lg:flex-1'` was removed. CitasAnalista is now a direct child of a grid with lg:items-stretch and grid-rows-[minmax(0,1fr)], so it always fills the row height.
Impact: This is intentional for "appointments remain full right column", and the browser test checks the rectangle. It is a visual change for the zero-citas case, which the test may not cover.
Recommendation: Confirm the browser test includes the zero-citas fixture. Otherwise, take a screenshot of that case once.
