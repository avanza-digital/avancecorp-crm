# Registro de organización

`movimientos.json` registra las carpetas trasladadas y las huellas de sus 646 archivos en el momento del traslado. Se comprobó que cada archivo conservó sus bytes inmediatamente después de moverlo. Las llamadas de Figma posteriores pueden actualizar su registro y añadir nuevas evidencias.

Las cuatro rutas anteriores de `output/` son enlaces a las carpetas nuevas. Los documentos mantienen la misma profundidad respecto a la raíz del proyecto para conservar sus enlaces relativos. Las notas del Vault, el PDF de origen y las imágenes de propuestas tienen accesos directos; no se duplicaron.

La reorganización no mueve archivos de la aplicación ni modifica componentes, dependencias, backend, permisos o fórmulas.
