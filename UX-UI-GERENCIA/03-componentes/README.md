Las diez áreas incluyen marca, indicadores, gráficos, período/regreso, tablas/listas, formularios, paneles, estados y movimiento. ECharts ya está integrado en Gerencia; Recharts y sus adaptadores se conservan para evaluar su encaje. Se aprovechan los controles existentes y su comportamiento, sin reemplazar la base tecnológica por motivos estéticos.

La biblioteca es la base de UX1. Su existencia no acredita todos los estados ni sustituye la comprobación de teclado, foco, móviles o significado de los datos.
